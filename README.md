# Operations

Personal organisation app. Current v0.1 is zero-cost and local-first.

## Run
npm install
npm run dev

## Current features
Today/Top 3, Quick Capture + Undo, Needs Review, Tasks, editable Areas, Routines/streaks, Projects/milestones, Notes/Resurfacing, People CRM, search, voice capture where supported, PWA shell, JSON backup.

## Next
Free hosted deployment, cloud sync, Google sign-in and two-way Google Calendar sync.
